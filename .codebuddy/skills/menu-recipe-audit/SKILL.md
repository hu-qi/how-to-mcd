# 菜单与家庭烹饪参考审核

## 输入

`web/home-guides.js` 品类指南、`web/shop.js` 官方菜单 UI、`src/recipes.rs` 与 `recipes/*.json` 社区完整食谱。

## 步骤

1. 枚举 `web/home-guides.js` 中的餐品类别、识别规则和兜底规则；每种真实菜单条目必须有入口，**有入口不等于有真实商业配方**。
2. 检查每条参考方法的范围、步骤、食材、器具和食品安全；不得凭空捏造具体店内工艺。
3. 区分「社区完整菜谱」（Rust 库提供）、「类目参考」（通用方法）和「信息不足」（无可核实配方）。
4. 确认商品、价格、营养等官方数据不会混进原创指南成为冒称的「官方复刻」。
5. 运行 Rust / WASM / Playwright 验证；线上真实菜单用只读官方 MCP 调用，只在受信任的 main CI 中注入 Secret。
6. 输出审核问题、修复建议、实际测试结果。**不制造不存在的执行日志**。

## 完成标准

全覆盖**指南入口**；用户明确知晓有些商品只有家庭参考而不是一对一复刻；无敏感信息泄露；无自动下单。
