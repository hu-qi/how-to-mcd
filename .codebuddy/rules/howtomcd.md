# HowToMCD 领域与安全规则

- Rust 的 `src/recipes.rs` 是完整社区食谱的权威数据源，WASM 与 CLI 必须保持一致。
- 官方菜单商品及其名称/价格/分类只能来源于实时 MCP 返回值。没有返回，不要 mock 并假称真实。
- 社区完整食谱 vs 品类家常指南 vs 未知商业配方必须用明显不同的标签。
- 为未识别商品提供可理解的「不具备配方」说明和人工填写食材参考，不要杜撰其组成。
- 食品安全：鸡肉 74°C、牛肉馅 71°C、鱼类 63°C；其他商品按适用的食安规则处理。
- 不得在源码、日志、网页、静态 artifact 中泄露任何用户 Token、个人地址或订单信息。
- CI 仅允许 read-only MCP 操作及询价。禁止自动创建订单和支付。
